<h3>📌 Observaciones y Recomendaciones</h3>

- Recomiendo usar un VPS de **Hostinger**, **Hetzner**, **Digital Ocean** o **AWS**. NO recomendamos ni animamos a usar otros VPS.
- **El Servidor necesita estar vacío** para efectuar la instalación de las herramientas. Ejecutar el Setup con otras herramientas puede acarrear la pérdida de datos.
- Se recomienda utilizar **Ubuntu 20.04**, con **mínimo de 4Gb y 2vCPU**. Es necesario analizar los requisitos de cada aplicación que se vaya a instalar.

---

<h3>💿 Cómo ejecutar el instalador</h3>
<p>Pensando en dejar la instalación de las herramientas lo más fácil posible, creamos un código corto que actualizará su servidor, descargará el script de setup y lo ejecutará. Todo para que cualquiera consiga usarlo.</p>

<p>Basta ejecutar este código en la terminal de su servidor:</p>

```
bash <(curl -sSL setuporion.optimadata.es)
```
<p>Después de esto basta esperar algunos instantes mientras el script se inicia y por fin, instalar las herramientas que desee.</p>
